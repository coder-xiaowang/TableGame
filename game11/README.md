# 截码战联机版

在项目根目录运行：

```text
node game11/signal-server.js
```

然后打开 `http://localhost:8797/`。

- 支持 4–8 人；允许不对称阵营，但每队至少需要 2 人。
- 玩家在大厅自行选择队伍并调整座位。
- 写提示限时 90 秒，团队猜码限时 60 秒。
- 合法猜测会随选择变化私密保存；超时由房主自动锁定最后一个草稿，完全未操作仍按未提交处理。
- 内置 440 个原创简体中文关键词。
- 另有一份以基础版英文 400 词为候选的英中审查表；仅将通过语义、地域性和重复检查的词加入运行词库。
- 同一玩家不能重复提示，提示不能直接包含本队关键词。
- 第一轮不拦截；两次成功拦截获胜，两次错误传讯落败，最多八轮。
