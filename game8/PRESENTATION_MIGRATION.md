# game8《璀璨宝石宝可梦版》桌面演出层迁移

## 迁移目标

用服务器权威事件表现精灵球、宝可梦和回合在训练家之间的真实流动，让拿球、保留、捕捉、进化和结算不再只是数字瞬间变化，同时严格保持暗牌保留的秘密边界。

## 事件与方向

| 事件 | 方向或效果 | 隐私 |
| --- | --- | --- |
| `game-start` | 首位训练家获得行动强调 | 公开 |
| `tokens-taken` | 供应区 → 行动训练家 | 公开 |
| `token-returned` | 行动训练家 → 供应区 | 公开 |
| `card-reserved` | 明牌市场 → 训练家 | 卡名公开 |
| `secret-reserve` | 指定等级牌堆 → 训练家 | 只公开等级，不含卡名和ID |
| `secret-reserve-private` | 指定等级牌堆 → 本人 | 仅持有者看到真实卡面 |
| `card-captured` | 市场或保留区 → 训练家 | 捕捉后完全公开 |
| `pokemon-evolved` | 旧形态 → 新形态强调 | 公开 |
| `turn-passed` / `mega-token-taken` | 跳过行动或领取扩展代币 | 公开 |
| `final-round` | 中央高优先级提示 | 公开 |
| `turn-start` | 下一名训练家获得行动强调 | 公开 |
| `game-result` | 胜者强调 | 公开 |

同一权威动作产生的主要事件和回合交接共用 `sceneId`，客户端只聚焦其中优先级更高的主要动作。进入最后一轮与最终结算单独建立高优先级场景。

## 播放策略

- 正常播放 1350ms；2 个场景开始追赶，5 个场景进入强压缩。
- 捕捉、进化、最后一轮、开局和胜负为高优先级事件。
- 首次进入或重连只建立游标，不重播旧事件。
- 演出层不接收点击，并支持系统“减少动态效果”。

## 实机验收

- [ ] 拿球时能看清各色精灵球由供应区移向行动训练家。
- [ ] 归还超过上限的球时方向相反，连续归还不会造成长时间积压。
- [ ] 明牌保留的卡名对所有人可见，并从对应市场指向训练家。
- [ ] 暗保留时其他玩家和旁观者只知道等级；只有本人看到真实卡面演出。
- [ ] 捕捉和进化有清楚的卡牌移动、训练家强调和中央说明。
- [ ] 自动结束回合不会额外重复主要动作，同一动作只出现一次中央播报。
- [ ] 玩家、旁观者的公开事件一致，重连与服务重启不会重放旧事件。
- [ ] 手机端操作区与训练家板块仍可点击，演出不会遮挡页面。
