# game14《脏小猪》桌面演出层迁移

## 目标

- 由权威服务端记录开局、回合、出牌、目标、结算、补牌、换牌和胜负演出。
- 用农场到小猪的方向轨迹表现行动，用中央短暂播报说明刚发生的事实。
- 保留吸附操作区和移动端单列农场，不让动画影响操作或服务器倒计时。
- 动画只解释已经完成的权威结算，不参与合法目标判断和回合推进。

## 事件与隐私边界

- 公开：行动牌牌名、行动者、合法目标玩家与小猪、状态变化、公开弃牌、公开的三张不可用牌、下一行动者和胜负。
- 私人：起手牌、每回合补到的牌、三张换牌后获得的新牌。
- 下雨事件只携带受影响小猪的公开位置，不携带任何玩家手牌。
- 旁观者接收与玩家相同的公开事件，但不接收任何私人事件。
- 猪舍、封门和避雷针属于持续保护规则；它们通过公开状态表现，不虚构规则中不存在的响应窗口。

## 验收标准

1. 定向牌按“出牌前摇—目标轨迹—结果变化—私人补牌—下一回合”顺序播放。
2. 下雨统一播报，并同时强调所有实际被洗净的小猪。
3. 无效果弃牌与超时弃牌能明确区分，均不误播牌面效果。
4. 三张换牌的旧牌公开，新牌仅换牌玩家可见。
5. 所有视图中的事件序号单调递增，多事件排队播放且重连不回放旧历史。
6. 旁观者和无关玩家不能从事件字段获得手牌或补牌结果。
7. 旧版本 2 SQLite 快照缺少演出字段时仍能恢复。
8. 规则、权威服务、旁观、持久化、共享演出和 UI 契约测试全部通过。
