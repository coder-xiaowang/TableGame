# Can't Stop 联机版

在项目根目录运行：

```text
node game10/signal-server.js
```

然后打开 `http://localhost:8796/`。可通过 `PORT` 环境变量修改端口。

## 第一版规则

- 2–4 人，使用四颗六面骰。
- 每次掷骰后将骰子两两配对，并选择一种可行组合推进。
- 每回合最多使用三条路线；相同点数可在同一路线上推进两格。
- 玩家可以继续掷骰，或扎营并固定本回合进度。
- 若掷骰后没有任何合法组合，本回合的临时进度全部丢失。
- 到达路线顶端并扎营后占领该路线；其他玩家不能再使用它。
- 率先占领三条路线的玩家获胜。
- 每次操作限时 30 秒：选择阶段自动选择首个合法组合，抉择阶段自动扎营，掷骰阶段自动掷骰。

## 物理骰子

骰子由 Three.js `0.185.1` 和 Rapier 3D compat `0.20.0` 在本地渲染。房主为每次投掷生成随机 seed；所有客户端使用固定 `1/120s` 步长预模拟同一组刚体轨迹，骰子停止后从实际朝上的面读取点数。依赖已固定在 `vendor/`，运行时不需要访问 CDN。

不支持 WebGL 的设备会跳过三维画面，但房主的物理结果和游戏流程仍会正常进行。
