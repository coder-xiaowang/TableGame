# 首页「今日一页」

首页读取同源的 `/daily-poem.json`，显示文件中的日期、诗句、作者和篇名。缓存缺失或无法使用时，纸签展示 HTML 内置的白居易《问刘十九》，没有采集日期。游戏服务和运营报表各自独立。

## 本地预览

在仓库根目录运行下列命令，默认缓存位于系统临时目录的 `tablegame-daily-poem/daily-poem.json`。取诗和预览命令也可以共用环境变量 `DAILY_POEM_DIR` 指定其他仓库外目录。

```sh
node homepage/scripts/update-daily-poem.mjs
node homepage/scripts/serve.mjs
```

## 将来部署

以下步骤供站长正常合并代码后执行。示例沿用现有主站的 `/srv/tablegame`、`tablegame` 用户、Node 24 和系统 cron。运行数据单独放在 `/var/lib/tablegame-poetry/`。

1. 建立供取诗任务写入、Nginx 可读取的目录。首次取诗与定时任务使用同一个文件锁。

   ```sh
   sudo install -d -o tablegame -g tablegame -m 0755 /var/lib/tablegame-poetry
   sudo -u tablegame env DAILY_POEM_DIR=/var/lib/tablegame-poetry /usr/bin/flock -n /var/lib/tablegame-poetry/update.lock /usr/bin/node /srv/tablegame/homepage/scripts/update-daily-poem.mjs
   ```

2. 把 Nginx 配置片段安装到配置目录。

   ```sh
   sudo install -m 0644 /srv/tablegame/ops/daily-poem-nginx.conf /etc/nginx/snippets/tablegame-daily-poem.conf
   ```

   在主域名 `zillionx.xyz` 现有 HTTPS `server {}` 内添加一行 `include /etc/nginx/snippets/tablegame-daily-poem.conf;`。配置仅公开一个 JSON 文件。运行 `sudo nginx -t && sudo systemctl reload nginx` 后，检查 `curl -fsS https://zillionx.xyz/daily-poem.json` 与首页纸签是否一致。

3. 启用现有 cron 的独立任务。

   ```sh
   sudo install -o root -g root -m 0644 /srv/tablegame/ops/tablegame-daily-poem.cron /etc/cron.d/tablegame-daily-poem
   ```

   每小时第 03、18、33、48 分钟检查缓存，以北京时间判断是否已更新。正常在零点后第 3 分钟选定当天的一句，其余检查只读缓存。若接口超时、返回错误或诗句缺少作者或篇名，任务返回非零状态，沿用上次成功的内容和日期，下一次调度再试。成功时先在同一目录写临时文件，再原子替换公开文件。

数据源采用[古诗词·一言 V1](https://gushi.ci/) 的 `https://v1.jinrishici.com/all.json`，读取 `content`、`author` 和 `origin`。
