# 拼豆内核基准实验台

从站点访问 `tools/bead-pattern/benchmarks/benchmark.html`。该页面没有加入公开工具入口，并设置了 `noindex,nofollow`。

## 使用方法

1. 运行“标准基准”，检查12张素材的三种推荐配置；
2. 展开结果下方的人工评测，填写五项1～5分评分和问题标签；
3. 导出评测JSON，作为当前内核版本的基线；
4. 修改算法后重新运行，导入旧JSON即可显示颜色数、碎片数和色差变化；
5. 发布前运行完整组合和自动化测试。

所有素材均为本项目专门绘制的合成SVG，仅用于算法回归，不包含网络下载或第三方版权素材。人工评分保存在当前浏览器的 `localStorage`，不会上传服务器。
