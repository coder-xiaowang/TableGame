# game21 间谍危机（Spyfall）

服务器权威、SQLite持久化并原生支持旁观的3～8人语音推理桌游。

## 体验外壳

页面采用“实时情报行动网络”设计：30个候选地点成为持续可查的地点档案库，玩家表现为散布在地图上的特工节点，问答、指认和提名通过中央上行链路传递。当前操作位于现场行动终端，私人地点与身份保存在加密任务卡中；规则、公开记录和旁观信息收纳在网络下方的独立情报抽屉。设计依据见 [VISUAL_DESIGN.md](VISUAL_DESIGN.md)。

本地启动：

```bash
node game21/signal-server.js
```

默认端口为 `8807`，可通过 `PORT` 修改。数据库默认位于 `game21/.data/game21.sqlite`，正式服务器建议设置：

```ini
GAME21_DB_PATH=/var/lib/tablegame/game21/game21.sqlite
```

## 桌面演出层

- 共享演出事件层表现提问方向、提问权交接、指认、匿名表决进度、超时提名和轮末揭晓。
- 动画只解释服务器已经接受的事实，不参与规则判定，也不会暂停服务器倒计时。
- 表决事件不携带赞成或反对值；导致窗口立即结束的反对票不会标识反对者，避免通过事件时序推断秘密选择。
- 旁观者与正式玩家接收同一份公开演出事件，结算前不会由此获得地点或间谍身份。

详细规则和数字化裁定见 `RULES.md`。
