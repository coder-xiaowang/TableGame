# Changelog

本项目的所有重要变更都会记录在此文件中。

## v0.14.6 - 2026-10-21

### Added

- 碎片自旋增加“随机”方向，每块碎片可独立选择顺时针或逆时针。
- 公转速度和自旋速度增加“非常高”档位。
- 长按动态增加“围绕鼠标旋转”，可选择不旋转、顺时针、逆时针或逐片随机方向。
- 长按动态增加半径大小，可选择高、中、低，并与远近分布密度组合生效。

### Changed

- 鸟群公转方向改由独立的“围绕鼠标旋转”选项控制，不再依赖右键旋转方向。

## v0.14.5 - 2026-10-20

### Added

- 长按动态增加碎片自旋速度，可选择高、中、低三档。
- 长按动态增加自旋同步程度，可选择完全同步、轻微不同步或完全随机。
- 长按动态增加围绕鼠标旋转的同步程度，可选择完全同步、轻微不同步、中等不同步或非常不同步。

### Changed

- 游戏工具栏的“换图”更名为“返回主页”，并移动到最左侧。
- 公转速度、公转同步、自旋速度和自旋同步改为独立参数，互不覆盖。

## v0.14.4 - 2026-10-20

### Added

- 在一秒内依次点击“设置 → 收起设置 → 设置”可解锁隐藏的“长按动态”设置行。
- 长按动态支持启用开关、三档公转速度、碎片自旋与方向、三档跟随灵敏度，以及三种远近分布密度。
- 隐藏设置行提供独立的“保存设置”按钮，保存时不会重新生成拼图。

### Changed

- 操作设置中的右键旋转方向现在也决定鸟群围绕鼠标顺时针或逆时针旋转。
- 自旋碎片在松手随机散开时会平滑回到原有拼图方向，避免产生无法正常拼合的任意角度。

## v0.14.3 - 2026-10-20

### Changed

- 鸟群半径改为偏向近距离的分布，多数碎片运行在近环，只有少数碎片进入远环。
- 远环碎片的环绕速度略低于近环碎片，使鸟群层次更加自然。
- 鸟群跟随改为同时限制最高速度和加速度的追逐模型；鼠标快速移动时会产生自然落后和追赶效果。
- 游戏说明补充鸟群远近分布与限速追逐行为。

## v0.14.2 - 2026-10-20

### Added

- 主页增加简单、容易和困难三个难度选项，并动态说明对应片数与提示次数。
- 主页难度会同步到游戏内难度设置，开始游戏或从主页上传图片时均会生效。

### Fixed

- 修复旋转组合在聚拢时中心坐标被重复旋转，导致部分碎片未正确集中的问题。
- 聚拢时为全部选中组合计算共同安全中心，避免靠近画布边缘时各组合被分别限制到不同位置。
- 修复聚拢后移动鼠标会取消鸟群计时、持续长按无法进入鸟群效果的问题。
- 鸟群起始位置改用实际渲染中心，保证从聚拢到环绕的动画连续。

## v0.14.1 - 2026-10-20

### Added

- 多选后持续按住 4.5 秒进入鸟群效果，碎片围绕按下位置旋转并平滑跟随指针。
- 鸟群状态松开左键时，从当前可见位置连续过渡到随机散开动画。

### Changed

- 多选聚拢的长按阈值调整为 0.5 秒，并增加持续 1 秒的飞行动画。
- 选中描边强度的默认档位由标准调整为柔和。
- 游戏说明补充聚拢动画和鸟群效果的操作方法。

## v0.14.0 - 2026-10-20

### Added

- 难度设置增加简单、容易、困难和自定义预设，并联动拼图数量与本局提示次数。
- 增加 -1 到 999 次的提示上限；-1 表示无限，工具栏显示已用次数与总次数并提供悬停说明。
- 图形设置增加柔和、标准和醒目三档选中描边强度。
- 游戏说明补充玩法、多选长按聚拢、右键菜单以及彩色“提示一对”提示语。

### Changed

- 选中反馈改为蓝色实线柔光，随选中拼片数量增加自动变细、变弱，并继续只描画组合外轮廓。
- 多选拖动不再动态聚拢；在选中碎片上长按约 0.4 秒后，一次性把全部选中组合聚拢到按下位置。
- 操作设置中的吸附滑块改为垂直居中对齐。
- 完整拼图停止操作后的自动归位等待时间由三秒缩短为 0.5 秒。
- 完成标题改为“拼好了，你真棒！”。

## v0.13.0 - 2026-10-20

### Added

- 增加 `Ctrl+A` 全选快捷键，并在右键菜单“全部”上提供快捷键提示。
- 完成后的欣赏状态支持拖动与旋转，停止操作三秒后自动旋正居中。
- 图形设置增加“应用材质”，可即时更新形状、材质与拼片差异，不重开游戏。

### Changed

- 选中轮廓改为黑白交替虚线，并只描画组合外侧边界，不显示已拼合的内部接缝。
- 右键规则改为三态：未选或单选时右键碎片直接旋转、右键空白打开菜单；多选时始终打开菜单。
- 设置面板增加独立的“难度设置”行，仅放置拼图数量和“生成拼图”。

## v0.12.1 - 2026-10-20

### Added

- 右键菜单增加“随机散开”，以随机方向和距离动画发射当前所有选中组合。
- 右键菜单增加“均匀散开”，按画布比例将当前选择尽量均匀地铺开，并居中不足一行的组合。
- 未选中任何组合时，两项散开操作与旋转、清除操作一同置灰。

## v0.12.0 - 2026-10-20

### Added

- 增加区分空白处与碎片位置的自定义右键菜单。
- 右键菜单提供全部、角块、边缘块、边缘与角块、内部块、三凸一凹、两凸两凹和一凸三凹八类选择。
- 右键菜单提供对当前选择旋转一次、两次、三次和清除选中；无选择时相关操作禁用。
- 单击画布空白处可取消全部选择。

### Changed

- 仅选中一个组合且右键命中它时保持直接旋转一次；无选择、多选或未命中当前选择时打开右键菜单。
- 选择效果恢复为沿拼片轮廓绘制的黑色虚线描边。
- 目标提示在“放到这里”后显示依据当前方向计算的“旋转 n 次”。
- 设置面板重组为图形设置、操作设置和快捷操作三行。
- “生成拼图”应用设置并开始新局；“保存设置”只保存旋转方向、吸附和提示时长，不重开拼图。

### Known Issues

- 右键菜单的旋转作用于当前所有已选可移动组合；已经吸附的组合仍作为整体旋转。
- 三凸一凹、两凸两凹和一凸三凹只匹配没有平边的内部拼片。

## v0.11.0 - 2026-10-20

### Added

- 增加 Ctrl 鼠标拖动框选；Ctrl+Shift 框选可在现有选择上追加。
- 增加沉浸模式，调用浏览器全屏并仅保留拼图区域和低干扰退出入口。
- 形状挑选增加“全部”，可一次选择所有可移动组合。

### Changed

- 选择反馈不再沿拼片边缘描色，改为与拼片轮廓分离的中性虚线外围框。
- “欣赏完整拼图”会清空当前多选和键盘选择状态。
- “应用设置”移动到全部设置项之后并使用强调色，保持在设置内容的右下侧。
- 操作说明更新为 Ctrl 框选与 Shift 点击追加。

### Known Issues

- 浏览器全屏需要由用户点击触发；若站点全屏权限被禁用，会显示权限提示并保持普通布局。
- 框选按可移动组合的中心点判定；已吸附组合会作为一个整体参与选择。

## v0.10.0 - 2026-10-18

### Added

- 完成成绩卡增加“欣赏完整拼图”，收起后可从工具栏重新查看成绩。
- 增加 2–30 秒自定义提示持续时间。
- 提示超时且目标尚未完成时，再次提示会恢复同一组；目标已完成时改为抽取新组合。
- 提示始终显示依据当前顺时针或逆时针方向计算的“旋转 k 次”。
- 增加角块、边缘块、内部块、凸起较多和凹口较多的一键形状挑选。
- 增加 Shift/Ctrl 点击多选，以及多选拖动时聚拢、松开后按数量散开的反馈。
- 时间和进度卡片增加支持鼠标悬停及键盘聚焦的动态详细说明。

### Changed

- 吸附合并时会维护多选集合与提示对象，不会留下失效组合。
- 完成成绩卡增加辅助技术可见状态和焦点管理。

### Known Issues

- 多选作用于可移动组合；若目标拼片已经与其他拼片吸附，会连同整个组合一起移动。
- 游戏说明正文仍按既定需求保持为空。

## v0.9.1 - 2026-10-18

### Added

- 增加键盘组合选择、方向键移动、快捷旋转和提示操作，并提供焦点轮廓、快捷键说明和读屏状态播报。
- 增加触屏双击同一拼片旋转方案。
- 开始界面和游戏界面增加内容暂为空的“游戏说明”；首次开始游戏自动打开一次，之后只手动打开。
- 增加 10×10 难度预设，并在图库第三项加入用户提供的“雪夜灯影”默认图片。

### Changed

- 开始界面移除难度与形状，只保留拼片差异、材质和开始操作。
- Canvas 根据设备像素比自适应清晰度，同时以总像素上限避免极端高 DPI 内存开销。
- 拼片图像与材质预渲染到缓存，减少 10×10 游戏中每帧重复裁剪和纹理合成。
- 超宽和超高图片统一按游戏区域双向约束缩放。
- 右键拖动期间使用指针捕获并持续阻止网页默认手势。

### Known Issues

- 游戏说明内容按当前需求保留为空。
- 浏览器或扩展在网页事件层之外实现的全局鼠标手势，仍需在对应浏览器或扩展设置中关闭。
- 后续规划功能记录在 `BACKLOG.md`。

## v0.6.0 - 2026-10-14
